# Termark Homebrew Tap

Install [Termark](https://www.termark.app/) with Homebrew on Apple Silicon and Intel Macs.

## Install

```bash
brew install --cask termark-app/tap/termark
```

Or tap the repository first, then install:

```bash
brew tap termark-app/tap
brew install --cask termark
```

## Update

Termark updates itself inside the app. To update through Homebrew instead:

```bash
brew update
brew upgrade --cask --greedy termark
```

## Uninstall

```bash
brew uninstall --cask termark
```

This cask installs the desktop app. For the `termark` command, use the CLI installer inside the app.

## 中文

通过 Homebrew 安装 [Termark](https://www.termark.app/)，支持 Apple Silicon 和 Intel Mac。

### 安装

```bash
brew install --cask termark-app/tap/termark
```

也可以先添加 tap，再安装：

```bash
brew tap termark-app/tap
brew install --cask termark
```

### 更新

Termark 支持应用内更新。如需通过 Homebrew 更新：

```bash
brew update
brew upgrade --cask --greedy termark
```

### 卸载

```bash
brew uninstall --cask termark
```

此 Cask 安装桌面应用。需要 `termark` 命令时，请使用应用内的 CLI 安装入口。
